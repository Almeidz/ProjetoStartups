
# 🚀 Radar de Startups Brasil
Projeto da Avaliação G1 da disciplina **Linguagem de Programação — Análise e Visualização de Dados com Python**.

Aluno: Lucas de Almeida Brugger Cavalcante
Professor:Alexandre Neves Louzada

## Pergunta de negócio

**Como investimento, setor, tecnologia e localização se relacionam com o desempenho financeiro das startups brasileiras?**

## Objetivos

- analisar investimento recebido e faturamento;
- comparar regiões, UFs, cidades e setores;
- avaliar tecnologias e níveis de inovação;
- acompanhar indicadores ao longo do tempo;
- calcular KPIs;
- analisar correlações;
- disponibilizar um dashboard interativo.

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Plotly
- GitHub
- GitHub Pages

## Funcionalidades intermediárias

- filtros múltiplos;
- KPIs dinâmicos;
- análise temporal;
- visualizações comparativas;
- dashboards organizados em seções;
- gráficos interativos.

## Funcionalidades avançadas

- correlação estatística;
- séries temporais com média móvel de 12 meses.

## Como executar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

Depois abra o endereço mostrado pelo Streamlit.
