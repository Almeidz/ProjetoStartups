## Pergunta de negócio

**Como investimento, setor, tecnologia e localização se relacionam com o desempenho financeiro das startups brasileiras?**

## Objetivos

- analisar investimento recebido e faturamento;
- comparar regiões, UFs, cidades e setores;
- avaliar tecnologias e níveis de inovação;
- acompanhar indicadores ao longo do tempo;
- calcular KPIs;
- analisar correlações;
- disponibilizar um dashboard interativo.
